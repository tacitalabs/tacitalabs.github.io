URLStrip 1.5.2 (Build 32)

What changed

  • Encrypted Brave Search result links are preserved without attempting to decode or resolve their opaque destination.
  • Clear guidance: open the result, then clean the destination URL.
  • Consistent current-URL presentation across native apps, extensions, CLI and website, including supported outer wrappers. Windows hides misleading tracking-impact information for encrypted results.
  • Additional shared URL-encoding and Instagram cleanup regression coverage. No new tracking rules or profile policy.

Normal URL cleaning stays local. Optional network resolution and privacy redirects remain explicit or opt-in.

The universal macOS package is Developer ID signed, notarized and stapled. The Windows installer, app and CLI are Azure Trusted Signing signed and timestamped.

Automated regression and package checks passed in their recorded scope. Remaining installed UI checks were waived and not run. Windows installed-file hashes rely on prior native receipts; the reproduced acceptance receipt lacks installed-file hashes.
