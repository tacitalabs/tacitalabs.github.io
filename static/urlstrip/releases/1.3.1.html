Desktop release notes

URLStrip 1.3.1 (Build 25)

Clearer desktop controls, visible update awareness, and verified Privacy Services updates.

What changed

  • Makes available app, rules, and Privacy Services updates visible from the macOS menu bar and Windows system tray.
  • Adds signed Privacy Services catalog updates with explicit check and install controls.
  • Adds clear, off-by-default controls for opening supported public X/Twitter and Reddit links with a selected privacy-friendly viewer.
  • Preserves explicit local choices and fails closed instead of silently switching services when a selected viewer becomes ineligible.
  • Simplifies the desktop Privacy Redirects screens while keeping advanced catalog controls available.
  • Aligns macOS and Windows on version 1.3.1 Build 25.

Privacy and network behavior

Normal URL cleaning stays local. Opening a privacy-friendly viewer contacts the selected service. Update checks request static version metadata from Tacita Labs and do not include the URL being cleaned.
