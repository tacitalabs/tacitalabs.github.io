## Confirm the Nuwber record before submitting it

Search by name and location, then open the individual result. Compare the
address, age, phone, or related-person details that are visible. Save the
profile URL only after you are confident it belongs to you.

That URL is the key input to Nuwber's official removal form and the reference
you will use for verification later.

## How the Nuwber removal process works

1. **Find and review the individual Nuwber profile.**
2. **Copy the complete profile URL.**
3. **Open Nuwber's official removal-link form.**
4. **Paste the profile URL and continue.**
5. **Enter an email address you control when the matched-record page asks for
   it.**
6. **Complete any CAPTCHA or browser challenge.**
7. **Open the verification email to finish the submission.**
8. **Revisit the saved profile after processing.**

> Reaching the email-sent page is not the final step. The broker's verification
> link completes the removal submission.

## Common Nuwber removal problems

### The removal form rejects the URL

Return to the individual person page and copy the full browser address. Search
result pages and shortened or partial links may not identify a removable
record.

### The page shows a challenge after I submit

Complete it in the same assisted browser. Check that the profile URL and email
fields still contain the expected values before continuing.

### The old profile redirects somewhere else

Search again by name and location. A redirect can indicate removal, a moved
record, or a broker-side change. Capture fresh evidence before deciding which
one happened.
