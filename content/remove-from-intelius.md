## Suppression and deletion are not the same thing

Intelius is part of the PeopleConnect network. Its privacy flow can suppress a
listing so it no longer appears in public people-search results. That is useful,
but it does not by itself prove that the underlying data was deleted.

Be careful with later deletion requests. Removing stored suppression state can
allow public-record data to return. The immediate privacy goal is to keep the
listing out of search and verify that outcome on every relevant site.

## How the Intelius suppression process works

1. **Find and review the Intelius record.** Save the result and the details
   that prove it belongs to you.
2. **Open the PeopleConnect suppression portal.**
3. **Provide the information the portal requests.** Review it before sending.
4. **Wait for the emailed check link.**
5. **Open that link promptly in the same browser session.** The broker may tie
   the link to the session that requested it.
6. **Complete the suppression and save the result.**
7. **Recheck Intelius and each related site where you saw a listing.**

> A shared owner does not guarantee that one suppression removed every public
> record. Check each site directly before treating the network as covered.

## How Infobreaker helps with Intelius

Infobreaker can scan Intelius, keep the matched record attached to the request,

## Common Intelius removal problems

### The email link fails in my normal browser

Return to the same assisted browser that requested it. Session-bound links may
not work when copied into a different browser profile.

### The portal says suppression succeeded, but Intelius still shows me

Allow for processing, then search again using the same name and location. Keep
the confirmation and the fresh search evidence together.

### A related site still has a listing

Treat it as a separate exposure. Use the relevant site's current privacy route
and verify it independently.
