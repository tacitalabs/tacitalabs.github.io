Begin with a unique MyLife profile URL

A broad MyLife search page is not enough for a reliable removal request. Open the individual profile, confirm that it belongs to you, and save its exact URL.

The profile may connect identity, location, age, and reputation-style material. Capture only what you need to review and remove the record. Do not share the profile publicly while asking for help.

How the MyLife privacy request works

  1. Find the exact profile. Confirm the person and save the unique URL.
  2. Open MyLife's official privacy request.
  3. Prepare the required details. The current flow can ask for your name, state, city, ZIP code, birth year, email address, and profile URL.
  4. Request and enter the email verification code.
  5. Review the filled request and complete the CAPTCHA.
  6. Submit only when the form still shows the correct profile information.
  7. Save the confirmation and recheck later.

MyLife may accept a privacy request while the public listing remains visible during processing. Record that honestly as submitted or still exposed until a later check proves otherwise.

How Infobreaker helps with MyLife

Infobreaker can search MyLife, identify a profile URL, and prepare the current privacy form using information from the local profile you control. It pauses for the emailed code and CAPTCHA because those are identity checks that should stay with you.

The app keeps the submitted request separate from the verification result. A broker acknowledgement does not become a verified removal automatically.

Common MyLife removal problems

The app found only a search page

Do not submit it. Open the individual person record first. The current privacy request needs a unique profile URL.

The emailed code expired

Request a new code and finish the form in one session. Check that the other fields still contain the expected values before submitting.

The listing is still visible after submission

Preserve the receipt, wait through the broker's processing period, and check again. If the listing remains, record it as still exposed and follow up using the broker's current privacy contact.

THE HONEST LINE

A request is not a removal.

Infobreaker records the request, preserves the evidence, and schedules a later check. It reports a verified removal only when that check shows the public listing is gone. Broker delays, declines, and re-listings remain visible instead of being folded into a success number.
