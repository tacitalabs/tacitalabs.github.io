Release notes

URLStrip 1.2 (Build 20)

A clearer link-cleaning workflow with optional, privacy-bounded resolution for opaque Instagram and Threads share links.

What changed

  • Added clearly labeled network resolution for Instagram and Threads /share/... wrappers whose destination is not present in the original URL.
  • Added an optional automatic-resolution preference. It is off by default.
  • Kept normal parameter removal and offline cleanup local. Network resolution uses an ephemeral, cookie-free session and strict service host allowlists.
  • Added consistent result provenance so URLStrip can explain whether a change was local, offline, network-assisted, or a functional transformation.
  • Added conservative Apple Maps and Google Maps conversion for supported pins, searches, and routes. Unsupported or potentially lossy links fail closed.
  • Added versioned JSON, stdin, and quiet-mode automation contracts to the macOS and Windows command-line tools.
  • Moved the most useful result actions to the top of the workflow and made unresolved-link status impossible to mistake for a completed clean.
