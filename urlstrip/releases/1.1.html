Release notes

URLStrip 1.1 (Build 19)

Desktop beta refresh that retires the unavailable X/Twitter privacy frontends, keeps X/Twitter tracker removal active, and updates both public desktop downloads to the same 1.1 Build 19 release line.

What changed

  • Retired the X/Twitter Privacy Redirect after Nitter-compatible public frontends ceased service following legal takedown demands. URLStrip no longer sends X/Twitter links to XCancel, Nitter, or custom Nitter-compatible hosts.
  • Kept normal X/Twitter tracking-parameter removal active. Cleaned links remain on x.com or twitter.com.
  • Kept the separate Reddit Privacy Redirect available with configurable Redlib-compatible frontends.
  • Added Command Guard on macOS and Windows to warn when copied terminal commands match risky patterns such as remote download-and-execute chains, PowerShell irm | iex, encoded payloads, persistence commands, and destructive shell actions.
  • Added an optional Neutralize risky commands setting. It is disabled by default; when enabled, URLStrip replaces risky clipboard commands with inert commented text.
  • Added Command Guard status, last warning details, rules version visibility, split notification controls, test-command helpers, and aggregate Command Guard stats without storing copied command text in stats.
  • Updated macOS menu bar feedback so the warning indicator reflects whether the current clipboard content is risky, and the menu preserves warning details if the notification is missed.
  • Reorganized desktop settings around a Status tab for recent alerts and a Settings tab for controls.
  • Updated Windows UI parity for the Command Guard settings, status, stats, welcome copy, and notification behavior.
  • Added Monetization Impact and Confidence detail to cleaned-link results on macOS and Windows so people can see the likely commercial value and confidence band of what was removed.
  • Expanded desktop stats on macOS and Windows with Today, 7 Days, 30 Days, and All Time windows plus category, impact, and confidence rollups.
  • Kept the fast cleaning flow lightweight while moving deeper explanation into intentional surfaces and linking to the public tracking methodology page.
  • Fixed the Windows issue where clicking Install Rule Update appeared to do nothing because the install button stayed disabled after a rule check.
  • Preserved user rule-state and custom rules across Windows rule bundle installs, improved error reporting, and added a 30-second timeout so failed installs surface clearly.
  • Retained opt-in Privacy Redirect support for Reddit links, with configurable Redlib-compatible frontends.
  • Added Copy Wayback Link support so users can copy a local Internet Archive lookup URL without submitting or archiving the page.
  • Fixed the Windows Privacy Redirect path for query-less canonical Reddit URLs, where the cleaner could previously bail out before rewriting the host.
  • Added Stable and Beta hosted rule channels on macOS and Windows so rule updates can move through beta review before stable promotion.
  • Improved Google local-result cleanup parity across desktop builds.
  • Updated manual macOS update checks to bypass cached release metadata so fresh desktop updates are detected reliably.
  • Aligned the shared desktop release metadata on URLStrip 1.1 (Build 19) for clean update checks and published hashes.
  • Refreshed the macOS Build 19 DMG with the Safari extension enabled, matching app and extension build metadata, and the latest desktop rule-channel support.
  • Kept the macOS Safari extension privacy-redirect escape-link handling for Redlib/Reddit frontends.
  • Refreshed the macOS DMG with an optional command-line tool that can be installed from Advanced Settings. The CLI supports normal URL cleanup, explicit stdin mode, usage/help/version output, quiet shell output, and JSON automation output.
