macOS release notes

URLStrip 1.3 (Build 22)

More control over privacy rules and sharing, plus the corrected macOS application icon.

What changed

  • Restored optional X and Twitter privacy redirects through XCancel. The redirect remains off by default.
  • Added optional daily rule checks and a verified automatic rule installation. These proactive controls are off by default and run only while URLStrip is active, not as a hidden background service.
  • Added conservative local alerts for unknown URL parameters so people can review possible tracking without automatic removal.
  • Added exact-name custom parameter blocklists with undo.
  • Improved Reddit short-link resolution and sharing while keeping network-assisted resolution explicit.
  • Repaired the missing application icon from the earlier Build 21 test package. Build 22 is Developer ID signed, Apple notarized, and stapled.

Platform status

This release is for macOS. The stable Windows download remains URLStrip 1.2 (Build 20) while the next Windows build completes native verification. The shared legacy desktop update feed therefore remains at 1.2 (Build 20) so Windows users are not offered a macOS-only update.
