URLStrip 1.5.1 (Build 31)

Extensible signed rule feeds for macOS and Windows.

What changed

  • Separate Stable and Beta signed rule-feed channels with fail-closed verification and verified-cache retention.
  • Support for extensible rule descriptions while preserving unsupported semantics safely.
  • A meaningful Windows Status empty state before any activity.

Privacy and compatibility

Normal URL cleaning stays local. Optional network resolution and privacy redirects remain explicit or opt-in. This release preserves the reviewed rule baseline; provisional rule additions and browser rollout are not included.

The macOS package is Developer ID signed, notarized and stapled. The Windows package is Azure Trusted Signing signed and timestamped. New releases can still receive Windows reputation warnings.
