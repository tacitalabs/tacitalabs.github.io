Desktop release notes

URLStrip 1.3.1: macOS Build 27 and Windows Build 26

A website-only macOS hotfix, with Windows and the shared desktop updater unchanged at Build 26.

macOS Build 27 hotfix

  • Restores the URLStrip application icon in the packaged macOS release.
  • Removes the redundant Updates summary from Advanced Settings while retaining the established App Updates and Rule Updates sections.
  • Always shows Privacy Redirect Service Updates in Privacy Redirects, regardless of whether Off, Nitter, or TwitterViewer is selected.

Build 26 foundation

  • Adds a clear three-way choice for supported public X/Twitter links: Off, a compatible Nitter service, or experimental TwitterViewer.
  • Defaults privacy-friendly viewer routing to Off and fails closed for unsupported links or ineligible services. URLStrip does not silently fail over to another service.
  • Ships signed Privacy Services catalog v3 with explicit check and install controls.
  • Makes available app, cleaner-rules, and Privacy Services catalog updates visible from the macOS menu bar and Windows system tray.
  • Ships cleaner rules 2026.09.28.2, including current Guardian, New York Times, and new global tracker coverage.
  • Preserves supported destination paths while rejecting malformed, hostile, and unsupported TwitterViewer routes.
  • Windows remains on the accepted signed version 1.3.1 Build 26 release.

Privacy and network behavior

Normal URL cleaning stays local. Opening a privacy-friendly viewer contacts only the service you selected. Network resolution runs only when requested or explicitly enabled. Update checks request static version metadata from Tacita Labs and do not include the URL being cleaned.

Website-only updater limitation

The shared desktop updater remains at version 1.3.1 Build 26 because it serves both macOS and Windows. Existing macOS clients will not receive an in-app Build 27 offer. macOS Build 27 is available from the Tacita Labs website and GitHub release only.
